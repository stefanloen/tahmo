TAHMO-WLM Flasher

This page allows updating the firmware of the WLM device. The following steps should be followed.

  1. Step 1: Connect the USB cable.
  2. Step 2: Shut down the device using the toggle switch.
  3. Step 3: Press and hold the 'BOOT' button next to the USB connector.
  4. Step 4: Turn on the device using the toggle switch. The device should now appear as a USB mass storage named RP2350.
  5. Step 5: The 'BOOT' button can now be released.
  6. Step 6: Click 'Deploy Firmware' and select the RP2350 Mass storage.

After following these steps correctly, the device will automatically disconnect and start normal operation (the green light will blink green). To connect to the device, use the Console.
